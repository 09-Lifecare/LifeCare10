# LifeCare - Student Health & Life Management Companion

“Stay healthy. Stay organized. Stay prepared. Stay in control.”

## Features

- **Smart Academic Planner**: Organize schedules, track tasks, and manage assignments
- **Health & Wellness Monitoring**: Track water intake, sleep, medications, nutrition, and physical activity
- **Mental Health Support**: Mood tracking, stress level monitoring, breathing exercises, and journaling
- **Daily Life Management**: Habit tracking, budget management, notes, and emergency contacts
- **Student Support System**: Peer connections, academic encouragement, and productivity insights
- **User Authentication**: Secure login/logout with role-based access
- **Data Persistence**: All data saved locally using browser localStorage
